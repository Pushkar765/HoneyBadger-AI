# HoneyBadger Overview

This document contains a high-level overview of the HoneyBadger project and its environment requirements.

## Purpose
- Manage AI and automation workloads on constrained VRAM hardware
- Provide an extensible assistant engine for local and remote service integrations

## Notes
- The project is tailored for RTX 3050 with a 3.5 GB VRAM allocation ceiling.
- `.env` stores service keys and runtime limits.
