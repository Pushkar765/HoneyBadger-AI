# HoneyBadger

HoneyBadger is a Python automation and assistant project tailored for an ASUS TUF A15 with 16GB RAM, 512GB SSD, and RTX 3050 4GB VRAM.

## Target hardware
- ASUS TUF A15
- 16GB RAM
- 512GB SSD
- NVIDIA RTX 3050 (4GB VRAM)

## Project structure
- `src/honeybadger/` – core application package
- `tests/` – unit tests
- `configs/` – configuration templates
- `docs/` – documentation
- `notebooks/` – notebooks and exploration
- `.env` – environment settings and VRAM limits
- `requirements.txt` – dependency list

## Setup
1. Create a Python virtual environment.
2. Install requirements: `pip install -r requirements.txt`
3. Copy `.env` and fill in actual credentials.
4. Run the application from `src/honeybadger/main.py`.
